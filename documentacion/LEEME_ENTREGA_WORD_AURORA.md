# Entrega documental Word - Aurora

Los documentos Word ajustados se encuentran en:

`documentacion/documentacion_word/`

Documentos clave para revisión:

- `MANUAL_USUARIO_AURORA.docx`: manual funcional para usuario final.
- `LINEA_BASE_CASO_NEGOCIO_AURORA.docx`: línea base, caso de negocio e historias de usuario/casos de uso.
- `VALIDACION_POST_DESPLIEGUE_AURORA.docx`: plan y resultados de pruebas funcionales. Este es el archivo donde se debe completar la evidencia de ejecución de pruebas con usuarios.
- `ARQUITECTURA_SISTEMA_AURORA.docx`: arquitectura con diagramas de contexto, componentes, despliegue, autenticación/roles y cargas Excel/staging/ETL.
- `GUIA_DESPLIEGUE_AURORA.docx`: guía de despliegue con Docker Compose y URL/ambiente real.
- `ACCESO_REPOSITORIO_AURORA.docx`: ubicación de versión cero en SharePoint y posterior gestión en Azure DevOps.

Los diagramas fuente en PNG se encuentran en:

`documentacion/diagramas_arquitectura/`
