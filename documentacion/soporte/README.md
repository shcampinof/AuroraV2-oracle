# Documentación de apoyo Aurora

Esta carpeta contiene documentación técnica complementaria, reglas de negocio, validaciones y notas operativas que sirven como soporte para mantenimiento del proyecto.

La documentación técnica formal se mantiene en `documentacion/documentacion_tecnica/`, incluida la documentación del modelo de base de datos.

## Estructura

| Carpeta | Contenido |
|---|---|
| `vision/` | Vista general del sistema y alcance funcional. |
| `reglas_negocio/` | Reglas de formulario, estados, historial y matriz Aurora/Celeste. |
| `base_datos/` | Flujo de datos, mapeos, SQL Oracle y diccionario de apoyo. |
| `api_integraciones/` | Endpoints API e integración SSO Azure AD. |
| `operacion/` | Docker, despliegue auxiliar, PWA offline y cargas staging/ETL. |
| `pruebas/` | Estrategia, protocolo, set de pruebas y validaciones funcionales. |

## Documentación técnica

- `documentacion/documentacion_tecnica/`: documentación técnica formal.
- `documentacion/documentacion_tecnica/base_datos/`: documentación técnica del modelo de base de datos.
